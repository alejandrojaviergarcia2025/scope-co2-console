# SCOPE CO2 — Deconvolution Console

A static, interactive walkthrough of the SCOPE CO2 project's software architecture, options, libraries, and hardware — built for a PI presentation, not a functioning application.

Plain HTML/CSS/JS, no build step, no framework, no server. `index.html` is the entire site; `assets/` holds real lab photos, real QDOAS screenshots, and the actual vendor datasheet PDFs it links to.

This is documentation/presentation material, not the project's real software. The actual deconvolution code lives in the main research repository: [scope-co2-deconvolution](../scope-co2-deconvolution) (ARPA-E IGNIITE, PI Dr. Anna Staerz, Colorado School of Mines).

## Publishing

This repo is meant to be served via GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
